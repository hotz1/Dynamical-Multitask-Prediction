# Dynamical-Multitask-Prediction

This is a repository containing my work for my Research Comprehensive Exam as part of my PhD program at the University of Toronto.

This project serves as an extension of the paper [*Efficient Spatio-Temporal Gaussian Regression via Kalman Filtering*](https://www.sciencedirect.com/science/article/pii/S0005109820302302), with updated Python code and an extension towards multi-output (vector-valued) responses which are not discussed in detail in the original paper.
